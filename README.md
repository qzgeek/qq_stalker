# QQ Stalker
<div align="center">
一个用于记录和查询QQ群聊消息的工具
</div>

---

## 📋 功能
1.  记录并储存QQ机器人所在群聊的全类型消息，包括**文字、图片、视频、表情包**
2.  支持通过近乎**自然语言**的命令，灵活查询历史聊天记录

---

## 🚀 开始使用
### 🔧 环境准备
| 依赖项 | 测试版本/要求 |
|:------ |:------------- |
| 操作系统 | Linux (Debian) |
| Python版本 | Python 3.9 |
| QQ机器人 | [NapCat](https://github.com/NapNeko/NapCatQQ)（需提前登录） |
| 数据库 | MySQL / MariaDB 11.8.5 |
| 离线下载 | 已配置的 AList |
| AI 接口 | DeepSeek API Key（或其他兼容AI接口） |
| 其他 | 一个聪明的大脑 😏 |

### 📦 部署步骤
1.  克隆代码仓库并安装所需依赖
2.  配置 MySQL 数据库，确保服务正常运行
3.  打开并编辑 **`配置.py`**，必填项：
    - 数据库配置信息
    - AList 配置信息
    - AI 接口配置信息
4.  运行主程序 **`app.py`**
5.  配置 NapCat 网络参数：
    - 添加 WS 客户端，填写对应 URL 与 Token
    - ⚠️ **重要设置**：消息格式选择 `Array` + 开启 `上报自身消息`
6.  部署完成，机器人即可开始工作

---

## 📝 查询指令
1.  **普通群成员**
    > 在群聊发送包含指定关键词的自然语言即可查询，**仅支持当前群聊**
    > 示例：
    > - `哈基米，帮我查查最近两天中包含"南北绿豆"的记录`
    > - `牢大我想找找有没有人发关于我想你了的消息`
    > - 更多语法参考 `ai工具.py` 内的提示词

2.  **超级管理员**
    > 支持**跨群查询** + **私聊查询**，额外可查询服务器运行状态
    > 服务器状态相关功能，详见 `系统状态.py`

> 💡 **小提示**：修改 `ai工具.py` 中的提示词，可以实现更灵活的查询逻辑

---

## ⚠️ 不足之处
- 消息类型支持有限，暂不支持**群文件、语音、合并转发、外部分享**等内容的记录或发送
- 文件上传模块无检测逻辑，采用固定等待时间后直接改名入库的方式
- 消息 URL 替换逻辑较为粗糙，更换存储链接或根目录后会导致文件失效
- 现有聊天记录查询方式效率偏低
- 等等等等......
